# Security policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature on the repository's **Security** tab.
Do not open a public issue for a vulnerability that could expose server files, permissions, or
administrative data. Include affected versions, reproduction steps, impact, and any suggested
mitigation. If private vulnerability reporting is unavailable, contact the repository owner
privately before disclosing details.

Never attach unredacted Minecraft server logs or configurations containing addresses, tokens,
credentials, player data, or private filesystem paths.
